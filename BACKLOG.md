## Сейчас в работе

**ПРИОРИТЕТЫ (решено с пользователем).** Строим техническую основу, баланс — позже.
Порядок: **(1) UI game-feel / VFX → (2) дека-модель + удобство сети → (3) геймплей-баланс**.
Баланс — долгая полировка, можно отложить; сейчас важнее техоснова и «ощущение». Движок —
**Godot 4** (менять не надо).

- [ ] **Фаза game-feel:** анимации (карты летят/ложатся, атака с рывком, вход существа),
      подъём-наклон под курсором, импакт (тряска + вспышка при уроне), частицы-искры,
      шейдер-свечение готового к атаке. Чистый код (Tween/AnimationPlayer/GPUParticles2D/
      шейдеры), без новых ассетов. **Архитектура:** клиент пересобирает борд на каждый `view`
      (`_rebuild`), поэтому межсостоянные анимации (карта летит рука→стол) требуют либо
      переживающих ребилд узлов, либо анимации входа внутри ребилда.
- [ ] **Дека-модель + сеть:** настоящие колоды (лимиты копий, кривая) вместо `demoDeck`
      (`server/src/main.cpp::demoDeck` — фикс. демо, оба игрока получают одинаковую колоду);
      удобство сетевой игры. Подробно — `APP_SHELL.md §4a`.
- [ ] **Базовый баланс-проход.** Числа сейчас стартовые (см. «Журнал решений → Баланс»).
- [ ] **Лог действий (история хода).** Видимая лента того, что произошло: кто что разыграл,
      атаки, смерти, эффекты, добор/мана, пассивы героя. Сейчас на борде виден только результат
      (новый `view`), но не «что случилось» — теряются эффекты соперника и цепочки. Варианты:
      серверные событие-сообщения (расширить протокол) либо клиентский дифф view→текст.
- [ ] **Заклинание Вспышки не поясняет «ослепление».** `Солнечный Удар` (`yellow_sunstroke`) —
      эффект `flash` инлайновый, но генератор текста выводит его как свойство «Вспышка N» (т.к. `flash` есть в
      `Glossary.KW`), а накладываемый статус **`blind`** не поясняется. Надо: не выводить `flash`
      как отдельное свойство, а пояснять статус «ослепление» (как для freeze/blind-заклинаний).
- [ ] **Выбор маны на бесцветную часть — реализовано, ждёт проверки в игре.** Когда бесцветную
      часть стоимости можно закрыть разными кристаллами, игрок тапает, чем платить. Движок:
      `ManaPool::pay(cost, genericPay)` + опциональный `genericPay` в `playCard`/протоколе
      (нет поля → старый greedy). Клиент: `_dispatch_play` считает неоднозначность (свободные
      кристаллы в ≥2 цветах и их больше, чем generic), при ней открывает `ManaSpendPicker`
      (тап-оверлей), иначе играет как раньше. Тесты движка зелёные; e2e клиента проверен
      харнесом. **Awaken пока greedy** (genericPay добавлен только в `play`) — кандидат на потом.

## Журнал решений

- **Баланс сета (сетка, чтобы тюнить от единой базы).** Ванильная стат-линия существа:
  `ATK+HP ≈ 2·T + 1`, где `T` = полная стоимость (generic + цветные пипы). Ключевики
  **выкупаются из этих очков** (≈: pierce/ward/regen/self_lifesteal/growth ≈ 1.5;
  shield/bypass/photosynthesis ≈ 2; provoke/lingering/stealth/haunt/compost ≈ 1;
  split/germinate/decoy ≈ 1.5). Цветные пипы дают лёгкую компенсацию (~+1 очко за
  требовательность). Кривая закрывает T1–T8, бугор на T3–4; провок-стены — высокий HP/низкий
  ATK; фотосинтез даёт **временную** ману (per-turn, не копится); `damage_all` бьёт и свою
  доску. Пятицветки — аспирационный верх (бомба-награда). **Числа стартовые, тюним по игре.**
  Балансная модель-скорер: `tools/balance.py`. Файл сета: `cards/sample.json` (синхрон в
  `client-godot/cards.json`).
- **Резонанс — снапшот при выходе** (не непрерывный): при призыве один раз впечатывается
  `resonance·кристаллы` в base ATK и в HP, дальше не растёт (иначе снежный ком в лейте).
- **Силы героя — пассивные, не кнопки** (не HS-активка-за-ману): постоянная черта, гнущая одно
  правило; нарочно условные и малой магнитуды. Герой = `CardDef` `type:hero`, пассив = именованный
  ключевик; герой не в колоде, рандом на старте (сервер). Лимит once-per-turn-пассивов — счётчик
  `Player.heroPowerUses` (свой у каждого). Лор: художники Призма-Арены; отображаемое имя — одно
  слово, мантия — лор. **Пробитый герою урон показывается всплывающей `-N` у медальона**
  (`_diff_hero_hp`), как у существ.
- **4 героя (≈равной силы):** Ирида «Призма»/`spectral_shift` (раз в ход кристалл как соседний
  цвет), Эреб «Затмение»/`lighteater` (существо, ударившее твоего героя, навсегда −1 атаки),
  Тициана «Палитра»/`palette` (первый за ход розыгрыш мультиколор-карты → добор), Гемма «Огранка»/
  `facet` (будишь ЛЮБУЮ банкованную карту; разбуженные +1/+1). Арты — единый стиль «живого света»
  (Эреб — ч/б-затменный). Кандидат на возрождение: Кьяра «Линза»/`clairvoyance` (арт `hero_lens.png`
  сохранён). Детали артов — `ART_HEROES.md`.
- **Схема стола — «фланговые медальоны»:** герой крупным портретом на левом фланге половины,
  колода/сброс/мана стопками справа, стол в центре.
- **Арты: герои — квадрат 1:1** (`1024×1024`, клиент кадрирует квадратом); карты — портрет 2:3.
- **Арт-стиль — «существа из живого света».** Свет/спектр — суть, а не косметика. Силуэт +
  внутреннее свечение, луч-цвет, крупные простые формы на тёмном фоне; варьируется только субъект.
  Субъекты — существа/явления света, не машины. Подробно — `ART.md`. **Имя и арт карты изображают
  один субъект** (синхронизировать при правке любого).
- **Жесты руки:** драг = разыграть (на стол/цель), **двойной тап = в ману**, клик по заклинанию =
  прицел. Цель выбирается ТОЛЬКО перетаскиванием (клик-таргетинг вырезан).
- **Лицо карты:** арт во весь кадр + тонкий цветной ободок + скримы + статусы `+N`; имени/правил на
  лице нет (компактный ТЕКСТОВЫЙ тултип, зум-арта нет — отверг пользователь).
- **Временная мана видна** — пипсы по `max(crystals, available)`, бонус (фотосинтез) с зелёным
  кольцом. **Выбор цвета банкуемой мультицветной карты — радиальный** (`mana_picker.gd`).
- **Freeze vs Blind разведены:** Заморозка = не атакует, но в защите бьёт в ответ. Ослепление =
  не наносит боевой урон вообще (ни в атаке, ни в ответ) → ослеплённого защитника можно убить
  бесплатно.
- **Морок (haunt) — иллюзия-токен:** копия наследует боевые ключевики, но НЕ перерождается и не
  сыплет споры (`token` гейтит триггеры). Клиент прячет триггер-ключевики у токенов и поясняет
  «Иллюзия уже не перерождается».
- **Сброс (graveyard) — пока чисто информационный:** наружу отдаётся только размер; ни один
  ключевик не читает содержимое. Задел под будущие механики (реанимация и т.п.).
- **DEF убрали:** 2 стата ATK/HP, бой — взаимный ATK (как HS). Стена = много HP + Маяк. Баффы
  «+N/+N» = +N ATK и +N HP.
- **Равенство типов сета:** моно поровну (3 на цвет), двуцветки поровну (1 на пару); нейтраль (5,
  белый утил) и пятицветки (5, общий id-префикс `prismatic_`) — отдельные пулы.

## Открытые вопросы / идеи

- **Ось различия — ГЕРОЙ, а не колода (кандидат, предложение пользователя).** Перевернуть: у всех
  **одна общая/пресетная колода**, а глубина переезжает в **героя** с **несколькими способностями**
  (кит), а не одной пассивкой. Балансить проще, вход легче, фокус на пилотировании. Возрождает
  активные силы героя в рамке «набор», а не одинокая HS-кнопка. Открыто: общая колода или N
  пресетов? сколько/каких абилок и их стоимость? цвет завязан на героя или на общую колоду?
  совместимо ли с «мана из своих карт»? **Не реализуем сейчас** — смена идентичности игры.
- **Архетип «бей по своим»** (жертвоприношение, авто-баффы от ран). Движок **готов**: селекторы
  `chosen_friendly_minion`/`chosen_any_minion` работают с любым действием — это чистый контент.
- **ambush и refract** — реактивные ключевики (перехват боя/таргета), **не реализованы** (отложены).
- **«Мана — контестед-ресурс»** — отложено: нужны ключевики атаки по мане / перекраски / сжигания.
- **Числовой баланс:** кривые стоимостей, компенсация второго игрока, редкость/лимиты сильных.

## Технический долг

- `Main.gd` — god-object (~1900 строк). Кандидаты на вынос: построитель тултипа, визуал карты,
  view-query хелперы — завязаны на `self/view/cards`, нужен аккуратный план (не просто перенос).
- **Дедуп UI-построителей**: повторяющиеся `Label.new()` с оверрайдами → хелпер `_label(...)`; то
  же для часто повторяемых StyleBox.
- **Движок (низкий приоритет, меняет поведение — только с тестами):** awaken-скидка применяется
  лишь к `generic` (карта `generic:0` + цветная стоимость не получает скидку — дизайн-вопрос);
  `buffStats` дублирует `recomputeContinuous` (safety net; убирать с тестом).

## Вырезанные ключевики (кандидаты на возврат)

Причина у большинства — дубль/слабая связь с цветом/ниша.

- **🔴** `penetrate` (урон игнорирует броню/щиты), `deepwound` (−N HP навсегда — дубль lingering).
- **🟡** `reveal` (раскрытие заготовок — дубль floodlight), `exposed` (нельзя спрятать + урон),
  `glare` (получив урон, ослепляет атакующего — 3-й вариант ослепления).
- **🟢** `seed` (смерть→росток — дубль spores), `proliferate` (токен каждый ход), `bloom` (бонус
  при N+ кристаллов — дубль resonance), `choke` (вражеский кристалл → твой росток).
- **🔵** `brittle` (двойной урон по замороженному — бессмысленно, оно и так нейтрализовано),
  `mass_freeze`, `sleep` (близко к freeze), `insomnia` (аура «враг не лечится»), `insight`
  (видно руку врага).
- **🟣** `phantom` (нельзя выбрать целью — дубль stealth), `corrupt` (−N/−N, слабо «фиолетовый»).
- **Концепты:** мимикрия, двойник/клон, полиморф (в 1/1); огненная ветка Красного — заменена на
  «красный свет».

## Пост-MVP (фичи)

- Web-экспорт клиента (Godot → HTML5) + деплой на VPS.
- Колодостроитель; полные сеты по всем 5 цветам; больше героев.
- Система рангов / прогрессия (высший ранг = титул Испытания Мастерства).
- **Кастомизация + «лудоманские» ивенты (идея пользователя):** кастомизация контента, скорее всего
  через **паки/наборы карт**, + азартные механики вовлечения (**колесо фортуны**, **лутбоксы**).
  Продумать: что выпадает (карты/косметика/рамки), экономика, честность дропа (pity), и как не
  скатить в pay-to-win.
- **Плагины (как HS Deck Tracker):** сторонние аддоны с вкладкой «Плагины» в меню. Нужен стабильный
  read-only API состояния матча/истории и песочница (чтобы не читали скрытую информацию).
- **Анимированные герои (MJ Animate → loop):** портрет иногда проигрывает короткий бесшовный луп.
  Пайплайн: MJ Animate → Loop + Low Motion → mp4 → Ogg Theora `.ogv` (Godot 4 играет .ogv нативно).
  В медальоне VideoStreamPlayer поверх статичного .png-фоллбэка; луп раз в ~15–30с или на событие.
- **Lua-«аварийный люк»** (sol2) для экзотических эффектов, если грамматики не хватит.
- Позиционная боёвка — **решено: НЕ делаем** (как HS).
