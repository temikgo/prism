# Prism

Модульная онлайн-ККИ 1v1 в духе Hearthstone, но со своей моделью — мир света и
спектра, где призмант материализует лучи Мега-Призмы в существ. Цель: играть с
друзьями. Движок построен так, чтобы карте можно было дать любое свойство.

## Навигация

- **[DESIGN.md](DESIGN.md)** — что есть игра: сеттинг, правила (бой, мана, типы, герой,
  колода), грамматика эффектов (модульное ядро), технический стек.
- **[EFFECTS.md](EFFECTS.md)** — вычищенный каталог ключевиков по 5 цветам (MVP-ядро).
- **[BACKLOG.md](BACKLOG.md)** — вырезанные-но-сохранённые идеи, открытые вопросы, пост-MVP.
- **[ART.md](ART.md)** — арт-пайплайн: фиксированный BASE-промпт, цвет→акцент, куда сохранять.
- **[engine/](engine/)** — C++-движок правил + сетевой слой (`engine/README.md`).
- **[server/](server/)** — WebSocket-сервер (одна комната на 2 игроков).
- **[client-godot/](client-godot/)** — Godot 4 клиент (рендер вида + действия).

## Статус

Дизайн зафиксирован (палитра 🔴🟡🟢🔵🟣, правила MVP). **Бой — 2 стата ATK/HP** (взаимный,
как HS). Движок: игровой цикл (мана-из-карт, добор, fatigue, победа), **23/32 цветных
ключевика + нейтральные исполняются**, очередь событий, иллюзии, континуальные баффы,
скрытый мана-ряд. Сетевой слой (`protocol.hpp`): редактированный вид под игрока +
применение действий. **Сервер**: WebSocket (ручной, без зависимостей), комната на 2,
рассылает каждому его вид. **44 теста + WS-смоук зелёные, CI на каждый push.** Дальше —
Godot-клиент (играть руками) и отложенные ключевики. Подробности — `engine/README.md`.

## Сборка и запуск

```
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build -j
ctest --test-dir build                 # тесты движка + формат-чек
./build/server/prism_server 8080 cards/sample.json
```

Сервер ждёт двух WebSocket-клиентов на `ws://<host>:8080`, раздаёт колоду из
`cards/sample.json` и шлёт каждому его (редактированный) вид после каждого действия.

**Клиент:** открыть `client-godot/` в Godot 4.3+, запустить два экземпляра, нажать
Connect. Клиент написан, но в Godot ещё не обкатан — см. `client-godot/README.md`.
