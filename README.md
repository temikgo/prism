# Prism

Модульная онлайн-ККИ 1v1 в духе Hearthstone, но со своей моделью — мир света и
спектра, где призмант материализует лучи Мега-Призмы в существ. Цель: играть с
друзьями. Движок построен так, чтобы карте можно было дать любое свойство.

## Над чем идёт работа

**Живая карта разработки: [temikgo.github.io/prism](https://temikgo.github.io/prism/)**
— каждый трек свой луч спектра, все коммиты на оси времени, этапы проекта, зум и
детали по наведению; тупики (что попробовали и откатили) — крестики. Страница
генерируется из [`roadmap.json`](roadmap.json) (плюс `git log`) скриптом
[`tools/build_roadmap.py`](tools/build_roadmap.py) и сама пересобирается на каждый
push (`docs/` не править руками).

## Навигация

- **[DESIGN.md](DESIGN.md)** — что есть игра: сеттинг, правила (бой, мана, типы, герой,
  колода), грамматика эффектов (модульное ядро), технический стек.
- **[EFFECTS.md](EFFECTS.md)** — вычищенный каталог ключевиков по 5 цветам (MVP-ядро).
- **[BACKLOG.md](BACKLOG.md)** — вырезанные-но-сохранённые идеи, открытые вопросы, пост-MVP.
- **[ART.md](ART.md)** — арт-пайплайн: фиксированный BASE-промпт, цвет→акцент, куда сохранять.
- **[engine/](engine/)** — C++-движок правил + сетевой слой (`engine/README.md`).
- **[server/](server/)** — WebSocket-сервер (одна комната на 2 игроков).
- **[client-godot/](client-godot/)** — Godot 4 клиент (рендер вида + действия).

## Статус

Играбельно end-to-end: C++-движок + WebSocket-сервер + Godot-клиент. **Бой — 2 стата
ATK/HP** (взаимный, как HS). Движок: игровой цикл (мана-из-карт с выбором, чем платить
бесцветную часть; добор, fatigue, победа), реализованные ключевики/эффекты, очередь
событий, иллюзии, континуальные баффы, скрытый мана-ряд, 4 героя с пассивами. Сетевой
слой (`protocol.hpp`): редактированный вид под игрока + применение действий. **Сервер**:
WebSocket (ручной, без зависимостей), менеджер комнат по коду+паролю. **Клиент**: полная
оболочка (меню/комнаты/выбор героя+колоды/матч), арт-стиль «свет на тёмном». Тесты движка
(doctest) + формат-чек + WS-смоук зелёные, CI на каждый push. Подробности — `engine/README.md`.

## Сборка и запуск

```
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build -j
ctest --test-dir build                 # тесты движка + формат-чек
./build/server/prism_server 8080 cards/sample.json
```

Сервер слушает все интерфейсы, ведёт комнаты по коду+паролю и шлёт каждому его
(редактированный) вид после каждого действия.

**Клиент:** `client-godot/` (Godot 4.3+). Запуск — `tools/run_client.sh` (импортирует
ресурсы и стартует) или открыть `project.godot` в редакторе и нажать Play. Адрес сервера
задаётся в Настройках, матч — через комнаты. Подробности — `client-godot/README.md`.
