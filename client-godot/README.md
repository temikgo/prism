# Prism — клиент (Godot 4)

Тонкий клиент: подключается к C++-серверу по WebSocket, рендерит **редактированный
вид** (то, что ему можно видеть) и шлёт JSON-действия. Правил не знает. Статику карт
(имена/стоимость/статы/текст) берёт из `cards.json` (копия `../cards/sample.json`),
рантайм — из вида сервера. UI собирается в коде, отдельные сцены не нужны.

Стиль — «свет на тёмном»: лицо карты это арт во весь кадр + тонкий цветной ободок,
гранёные кристаллы-гемы для ATK/HP, SVG-иконки статусов; имя и правила — в тултипе по
наведению (на лице текста нет). Под игроком — медальон героя, стол, и колонка справа
(мана крупными кристаллами, мана-ряд, стопки колоды/сброса).

Оболочка: главное меню → выбор героя+колоды → комнаты по коду+паролю → матч. Логотип
PRISM — процедурная гранёная призма-эмблема. Фон — общий шейдер вихревой энергии за
всеми экранами.

## Как запустить

1. Сервер из корня репо:
   ```
   cmake -S . -B build && cmake --build build -j
   ./build/server/prism_server 8080 cards/sample.json
   ```
2. Клиент: `tools/run_client.sh` (импортирует ресурсы встроённым Godot и стартует) —
   или открыть `project.godot` в Godot 4.3+ и нажать Play (F5).
3. В клиенте: **Настройки** → адрес сервера (по умолчанию `ws://127.0.0.1:8080`), затем
   **Играть** → выбрать героя и колоду → **Создать**/**Войти** комнату по коду+паролю.

Игра с другом по сети: хост поднимает сервер + туннель (ngrok), друг вписывает публичный
адрес в Настройки. Godot принимает `ws://` и `wss://` нативно.

## Управление

Цель выбирается **только перетаскиванием** (клик-таргетинга нет):

- **Карта в руке** → тащи на свой борд (разыграть существо/ауру) или прямо на цель
  (заклинание/прицел). **Двойной тап** по карте — положить в ману.
- **Своё существо** → тащи на вражеское существо или на медальон вражеского героя (атака).
- **Awaken-карта** в своём мана-ряду → тащи как карту из руки.
- Если бесцветную часть стоимости можно закрыть разными кристаллами — всплывает пикер,
  тапни, чем платить.
- Выбор цвета банкуемой мультицветной карты — радиальный пикер.
