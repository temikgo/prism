# Prism — клиент (Godot 4)

Тонкий клиент: подключается к C++-серверу по WebSocket, рендерит **редактированный
вид** (то, что ему можно видеть) и шлёт JSON-действия. Правил не знает. Статику карт
(имена/стоимость/статы/текст) берёт из `cards.json` (копия `../cards/sample.json`),
рантайм — из вида сервера. UI собирается в коде (`Main.gd`), отдельные сцены не нужны.

Карты рисуются плашками: цветная рамка по цвету карты, бейдж стоимости (generic-число
плюс цветные пипсы), имя, область арта (`res://art/<id>.png`, если файл есть — иначе
цветная заглушка), текст, статы ATK/HP снизу и текстовые метки статусов (ICE/SHLD/
HID/BLIND/ZZ). Под игроком — мана-пул, **мана-ряд** (рубашки плюс свои awaken-карты,
помечены `AW`) и список аур.

> Статусы/статы сейчас текстом-плейсхолдером, потому что дефолтный шрифт Godot не
> содержит символов вроде сердца/щита (рисует «тофу»). Реальные иконки (`TextureRect`
> с PNG/SVG) — задача полировки Phase A; места изолированы в хелперах `_status_text`/
> `_stats_node`/`_cost_node`.

## Как запустить (хотсит на одной машине)

1. Собери и запусти сервер из корня репо:
   ```
   cmake -S . -B build && cmake --build build -j
   ./build/server/prism_server 8080 cards/sample.json
   ```
2. Открой папку `client-godot/` в **Godot 4.3+** (Import → выбрать `project.godot`).
3. Запусти проект (F5) **дважды** (два окна) — или экспортируй и открой две копии.
   В каждом окне нажми **Connect** (адрес по умолчанию `ws://127.0.0.1:8080`).
4. Первый подключившийся — игрок 0, второй — игрок 1. Сервер раздаёт демо-колоду и
   начинает партию.

Играть с другом по сети: он указывает `ws://<твой-IP>:8080` (порт проброшен/в одной
сети). Публичный `wss://` — через реверс-прокси (nginx/caddy), код сервера не меняется.

## Управление

Основной способ — **drag-and-drop** (с клик-фолбэком на случай, если перетаскивание
капризничает):

- **Карта в руке** → тащи на свой борд, чтобы разыграть; на зону **`TO MANA`**, чтобы
  положить в ману; заклинание с целью — тащи прямо на вражеское существо.
- **Своё существо** → тащи на вражеское существо или на полосу **ENEMY HERO**, чтобы
  атаковать.
- **Awaken-карта** в своём мана-ряду (помечена `AW`) → тащи как карту из руки.
- **End Turn** — передать ход.

Клик-фолбэк: клик по карте/существу выбирает его, затем клик по цели завершает действие.

Выбор цвета многоцветной маны и реальные арт-иконки — следующие шаги Phase A.
