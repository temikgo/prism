# Handoff: Prism — игровой борд (game board redesign)

## Overview
Премиальный визуальный редизайн **игрового экрана (борда)** для онлайн карточной
игры 1v1 «Prism». Тема: «существа из живого света» — спектр, призма, преломление;
тёмная атмосферная сцена, неоновое свечение, «световой стол-арена». Это интерактивный
мокап одного хода: drag-and-drop карт из руки на стол, разыгрывание заклинаний по целям,
конвертация карт в ману, awaken-карты прямо из банка, медальоны героев, растущий банк
маны, стопки колоды/сброса, полка аур и рука прямым рядом.

Формат: десктоп-браузер, ландшафт 16:9 (фиксированный канвас 1600×900 со скейлом под
вьюпорт, letterbox на чёрном). Весь текст — русский (кириллица обязательна). Без эмодзи.

## About the Design Files
Файлы — это **дизайн-референс в HTML/CSS/React (через Babel-in-browser)**. Это прототип,
показывающий задуманный внешний вид и поведение, **а не продакшн-код для копирования**.
Задача — **воссоздать эти экраны в вашей кодовой базе** (React/Vue/игровой движок/нативный
клиент), используя её паттерны. Реактовая логика здесь намеренно простая (один ход) — берите
из неё **визуальную систему, токены, раскладку и поведение взаимодействий**, а состояние и
сетевую часть стройте по правилам вашей игры.

## Fidelity
**High-fidelity.** Финальные цвета, типографика, отступы, тени, свечение, интеракции.
Воссоздавайте попиксельно по токенам ниже. Арты существ и портреты героев — фиксированные
иллюстрации (см. «Assets»), не редизайнить.

## Layout (сверху вниз)
Фиксированный stage 1600×900; внутри flex-column, padding 16px 36px 0, gap 12px:

1. **Индикатор хода** (`.turnbar` / `.turn-pill`) — центрированная стеклянная пилюля:
   «ВАШ ХОД» / «ХОД СОПЕРНИКА» (800, letter-spacing .16em, uppercase, свечение акцентом
   стороны) + точка-разделитель + «ход N» (числовой шрифт) + кнопка «сменить». Акцент
   `--turn-accent` = `--me` (свой ход) / `--foe` (ход соперника). НЕТ призма-логотипа
   (был убран — пилюля чисто текстовая, паддинг 9px 14px 9px 26px).
2. **Полоса соперника** (`.rail.foe`) и **3. Полоса игрока** (`.rail.me`) — горизонтальные
   стороны. Каждая = `[медальон героя] | [полка аур] | [ряд существ] | [колонка ресурсов]`.
4. **Рука** (`.hand`) — прямой ряд карт снизу по центру (НЕ веер, см. ниже).
5. **Памятка** (`.hint`) — строка подсказок внизу.

### Side rail (`.rail`)
flex-row, align stretch, gap 18px, padding 14px, border-radius 22px. Тёмное стекло:
`--panel-fill` + тонкий верхний градиент акцентом; бордер
`color-mix(in oklab, var(--side) 38%, var(--panel-stroke))`; `backdrop-filter: blur(var(--glass-blur))`;
многослойная тень (drop + inset top highlight + inset 1px акцент + внешнее свечение).
`--side` = `--foe` / `--me`. Активная сторона (`.is-active`) — свечение и бордер усилены.
Поле при перетаскивании существа подсвечивается как легальная зона (`.drop-legal`):
диагональная штриховка акцентом + inset-обводка + внутреннее свечение.

## Card (`.card`) — существо / карта руки
Единый компонент; в руке крупнее (172×238) чем на столе (148×206), border-radius 13px.
Оправа (chrome) спроектирована **вокруг фиксированных стат-гемов и иконок** — не наоборот.
- **Слои**: `.art` (арт во весь кадр, cover; для зарезервированных — `.art.placeholder`
  с радиальным градиентом в цвет карты + диагональная штриховка + `.ph-tag` моноширинным),
  `.art-scrim` (вертикальный затемнитель верх/низ для читаемости), `.rim`
  (**тонкий светящийся ободок = цвет карты** — ключевой принцип, `inset 0 0 0 1.5px` +
  внутреннее свечение `--rim`).
- **Стоимость** `.cost` (верх-лево): число (числовой шрифт) + ряд **пипсов** `.pip` (по
  одному на каждый требуемый цвет маны, свечение).
- **Статусы** `.status` (верх-право): круглые бейджи 24px с **нашими тонколинейными SVG**
  (freeze, blind, shield, ward, stealth, taunt, haste). НЕ заменять иконки.
- **Стат-гемы** (НАШИ гранёные октагоны, НЕ редизайнить): **атака** `.stat.atk` (низ-лево,
  жёлтый) и **здоровье** `.stat.hp` (низ-право, зелёный; при ранении `.hurt` — красный,
  белый текст). Сидят в затемнённых «нишах» `.nook` (radial-gradient) — читаются на любом арте.
  У существ ТОЛЬКО два стата (атака/здоровье); брони у существ НЕТ.
- **Состояния**: `:hover` — подъём `translateY(-6px) scale(1.03)` + усиленное свечение;
  `.targetable` (легальная цель заклинания) — пульсирующая обводка (`@keyframes pulse`),
  цвет `--me`, для существ соперника `.foe-target` — `--foe`, cursor crosshair;
  `.dragging` — opacity .28; `.summoning` — анимация призыва (`@keyframes summon`);
  `.spectrum` (showpiece «Призматический Государь») — ободок-радуга через `conic-gradient`
  с mask-composite.
- **Статус-оверлеи на весь кадр** (`.fx`): `.fx-freeze-layer` (ледяная корка, голубой
  screen-blend), `.fx-stealth` (арт opacity .55 + штриховой контур), `.fx-shield-layer`
  (голубой купол), `.fx-ward-layer` (золотое кольцо).
- **Провокатор** (`.provoke` + `.provoke-frame`): золотая структурная рамка с угловыми
  скобами + золотое свечение — «по мне обязаны бить».

## Hero Medallion (`.medallion`)
Ширина 150px. Тег стороны «СОПЕРНИК»/«ВЫ»; **реальный портрет** (`.portrait .face`,
background-image, position 50% 22%) + `.portrait-sheen`; **броня** `.hero-stat.armor`
(октагон, `#BCD6FF`, низ-лево) и **здоровье** `.hero-stat.hp` (октагон; me — синий,
foe — красный, низ-право); имя героя (800, свечение акцентом). Броня — ТОЛЬКО у героя,
рядом с его здоровьем.
- **Способности** (`.abilities` → `.passive`): у героя может быть **несколько** способностей —
  ряд круглых бейджей с тонколинейными иконками под именем. **Описание открывается у КАЖДОЙ
  способности отдельно** (тултип kind «Способность», cursor help), а не у героя в целом.
  Данные: `hero.abilities = [{icon, name, desc}, …]` (есть fallback на одиночную
  `passive`/`passiveName`/`passiveDesc`). Демо: Ирида — «Преломление», «Световой рывок»;
  Кейра — «Пожиратель света», «Ночной взор».

## Aura shelf (`.aura-shelf`) — полка аур
Квадратные арт-плитки (`.aura-tile` 58×58, ободок/свечение цветом ауры) сбоку от поля,
свои и вражеские. **Один столбец со скроллом** (`.aura-tiles`: flex-column, gap 6px,
max-height 194px, overflow-y auto) — как банк маны: при многих аурах (6+) скроллится
внутри, остаётся в один столбец, НЕ расширяется в поле и не сталкивается с существами.
Без подписей на плитках (описание — в тултипе при наведении).

## Resource column (`.resources`) — мана/банк/awaken/стопки
Ширина 252px. Сверху вниз:
- **Банк маны** (`.bankpool` → `.bank-row`): мана растёт НЕОГРАНИЧЕННО. Каждый ход игрок
  банкует карту → +1 кристалл выбранного цвета, поэтому в банке **по нескольку каждого
  цвета** (не фиксированные «5+1»). Банкнутая карта = `.bankcard` (рубашкой вниз 24×32 +
  фасеточный `Crystal`). Состояния кристалла: **доступен**; **потрачен** (`.spent` —
  grayscale + затемнение); **временный бонус хода** (`.temp` — зелёное пульсирующее кольцо
  `.temp-ring`, «фотосинтез», мана только на этот ход). Пул сгруппирован по цвету
  (COLOR_ORDER), переносится в ряды, capped-height + внутренний скролл при переполнении.
  Лейбл «МАНА · БАНК N/M» (доступно/всего).
- **Awaken** (`.awaken-row` → `.awaken`): ключевик. Карту с awaken, забанкованную в ТВОЙ
  мана-ряд, можно разыграть ПРЯМО оттуда. Показана РАСКРЫТО — золотая мини-карта 54×76
  (арт + имя + atk/hp) с золотой рамкой/свечением и тегом:
    - `mode:'awaken'` → играется **за стоимость** (ценник = cost), тег «разбудить»;
    - `mode:'decoy'` → отлежав N ходов, разбуживается **«без доплаты»** (платится только
      её кристалл), зелёный акцент, тег «без доплаты», ценник «◆».
  Доступна по мане → яркая с глоу; недоступна → `.locked` (grayscale, серые ценник/тег,
  не кликается).
- **Прожектор (floodlight)**: пока он у тебя — **вражеский мана-ряд раскрывается**: вместо
  рубашек показываются компактные face-up превью банкнутых карт врага (`.bankprev` 26×34,
  арт + ободок цветом карты) под жёлтым лейблом «МАНА СОПЕРНИКА · ПРОЖЕКТОР» (`.res-label.flood`
  + иконка `flood`). Это состояние живёт на стороне соперника (`foeRes.revealed`).
- **Стопки** `.stacks`: `.pile` «колода» N, «сброс» N, «рука» N (иллюзия стопки карт через
  псевдоэлементы; число — числовой шрифт).

## Hand (`.hand`) — рука
**Прямой ряд, БЕЗ веера и без поворота** (ранее был fan с rotate — убран, т.к. дуга
опускала крайние карты на памятку). Карты с лёгким горизонтальным нахлёстом (`--ov`,
адаптируется к числу: -18px при ≤5, до -64px при 10), `align-items:flex-end`, приподняты
над памяткой (`bottom:54px`). **Z-index растёт слева направо** — поверх всех лежит **самая
правая карта** (`fan(i) → zIndex:10+i`). Hover: `translateY(-30px) scale(1.06)`, нахлёст
раздвигается, карта выходит на верх, показывается имя. До 10 карт без вылета за stage.

## Hover tooltip (`.cardtip`) — описание карты
При наведении на **любую** карту (рука / стол / мана-кристалл / awaken / аура / превью под
прожектором / **способность героя**) показывается попап дизайн-системы: имя, тип («Существо» /
«Заклинание» / «Аура» / «Способность» / «Мана» / «Awaken»), цвет, стоимость, атака-здоровье, эффект
и расшифровка статусов. Реализован делегированием: один `pointermove`-листенер на корне
борда читает `data-tip` (JSON) ближайшего элемента с этим атрибутом, дедуп по элементу
(`tipKeyRef`), скрывается при драге. Позиционируется над/под якорем по месту.
Сам медальон героя тултип НЕ открывает — только каждая способность отдельно.

## Interactions & Behavior
- **Drag-and-drop из руки** (`pointerdown`→`pointermove`→`pointerup`, порог ~6px): плавающий
  «призрак» (`#drag-ghost`, fixed, вне scale-stage). Существо → над `.me-field` поле
  `.drop-legal`; дроп → списать ману, добавить существо, `summon`-анимация, тост. Заклинание
  (`type:'spell'`) → легальные цели = существа соперника (`.targetable`); дроп на цель →
  списать ману, нанести `dmg`, `.hurt`, при hp≤0 убрать; мимо → тост-предупреждение.
- **Атака — стрелка-луч** (ключевой боевой жест; «стрелка от атакующего на цель»): зажимаешь
  СВОЁ существо на столе (`onAttackStart` на `.me-field .card`) и тянешь. От центра атакующего
  к курсору рисуется светящаяся SVG-стрелка (`#attack-arrow`, fixed full-viewport, вне
  scale-stage; жёлто-красный градиент `atkGrad`, бегущий пунктир `atkFlow`, поворачивающийся
  наконечник, ориджин-точка; лёгкий изгиб дугой). Легальные цели подсвечиваются (`.atk-legal`
  — красный пульсирующий ободок), цель под курсором ярче (`.atk-hot`); стрелка краснеет над
  валидной целью (`data-valid`), тусклая над пустотой. Дроп на цель → **обмен уроном**
  (атакующий бьёт atk по цели, цель отвечает своим atk; павшие hp≤0 убираются), анимация
  удара `.clash` на обоих, тост. **Удар по герою** — дроп на `.medallion.foe` (легален только
  если нет провокатора), `.hero-hit`-вспышка, hp героя (state `foeHp`) уменьшается. Правила
  целей (`legalTargets`): **провокатор** (taunt/provoke) перетягивает все атаки на себя (и
  герой, и остальные нелегальны); **незримые** (stealth) нельзя выбрать целью; **замороженное**
  или с 0 атаки существо атаковать не может (тост). Атака — только в свой ход.
- **Awaken-клик** прямо из банка → выкладывает существо (за стоимость или «без доплаты»),
  summon-анимация, тост.
- **Карта → мана (двойной клик по карте руки)**: любая карта = +1 кристалл в банк. Если
  карта **одноцветная** — конвертируется сразу в этот цвет. Если **мультицветная** (несколько
  разных цветов в `pips`) — открывается **пикер выбора цвета** (`.manapick`, компонент
  `ColorPicker`): поповер «В какую ману?» над картой с фасеточными кристаллами-вариантами
  (по разным цветам карты) — клик выбирает цвет. Пикер закрывается по Esc / клику мимо /
  после выбора. (В исходной игре это была круговая диаграмма-секторы — заменена поповером.)
- **Кнопка «сменить»** → me↔foe (на foe инкремент номера хода), меняет акцент пилюли и
  активную полосу.
- **Creature-row scaling**: ряд существ вмещает до 8 на сторону **равномерным масштабом**
  (`.field-inner` transform: scale) — карты НЕ перекрываются, при ≤6 масштаб 1.
- **Тосты** (`.toast`): всплывающее уведомление сверху, 1.7s; `.warn` для предупреждений.
- **Stage scaling**: 1600×900 масштабируется `transform: scale(min(vw/1600, vh/900))` по resize.

### Mana spend rule
Тратить нужно `cost` единиц: сначала цветные кристаллы, бесцветный — в последнюю очередь.
Доступной маны < cost → действие отменяется (тост «Недостаточно маны»). Подставьте реальные
правила соответствия цветов пипсам.

## State (демо, React useState — ориентир по данным)
- `turn` ('me'|'foe'), `turnCount`.
- `foeBoard`, `myBoard` — существа `{id, side, color, name, art|phTag, cost, pips[], atk, hp,
  hurt?, provoke?, spectrum?, statuses[], desc}`.
- `hand` — карты `{id, side, type:'creature'|'spell', color, spectrum?, name, art|phTag, cost,
  pips[], atk?, hp?, dmg?, desc}`.
- `mana` (мой банк) — `{color, spent?, temp?}[]`, растёт неограниченно. Конвертация карты добавляет
  `{color}` выбранного цвета (для мультицветных — через `ColorPicker`).
- `myAwakens` — `{id, name, art, color, cost, atk, hp, available, mode:'awaken'|'decoy', statuses[]}[]`.
- `foeHp` — здоровье вражеского героя (принимает урон от атак).
- `hero.abilities` — `{icon, name, desc}[]` (несколько способностей на героя).
- `dragId`, `summonId`, `attacking`, `picker` (выбор цвета маны), `toast`, `tipInfo`.
- Производные: `availCount(mana)`, `spendMana(mana, n)`, `rowScale(n)` (масштаб ряда существ),
  `fan(i)` (z-index руки — правая карта сверху), `legalTargets()` (легальные цели атаки).

## Design Tokens

`--ink-dim #9aa0bd`, `--ink-faint #5d6280`.
**Стекло:** `--panel-fill rgba(15,17,30,0.55)`, `--panel-stroke rgba(255,255,255,0.085)`,

`--rail-radius` 22px.
**Типографика:** UI — **Manrope** (400–800); числа (стоимость/статы/счётчики) —
**Chakra Petch** (`--num`); подписи-теги uppercase, letter-spacing .14–.2em.
**Скругления:** card 13, rail 22, medallion/portrait 16/14, pile 11, aura/awaken 12/8, бейджи pill/круг.
**Свечение:** drop-shadow + inset top highlight + цветное свечение через
`color-mix(in oklab, <accent> N%, transparent)`, масштаб на `--glow`.

### Direction variants (3 направления, `#stage[data-dir]`)
- **glass** — сдержанный премиум (дефолт). **neon** — усиленное свечение (`--glow 1.5`),
  плотнее фон. **prism** — спектральная кромка на полосах (градиентный бордер red→violet
  через mask-composite), радужный оттенок пилюли, `--glass-blur 20px`, `--motif .92`.

- `components.jsx` — `PALETTE`, `COLOR_RU`, `tip()` helper, иконки (`Icon`/`ICONS`/`STATUS`),
  гранёный бейдж (`HexBadge`), кристалл (`Crystal`), карта (`Card`), медальон (`Medallion`),
  полка аур (`AuraShelf`), банк (`BankCard`/`BankPool`/`BankPreview`), awaken (`AwakenCard`),
  колонка ресурсов (`Resources`). Прим.: `PrismGlyph` остался в коде, но в индикаторе хода
  больше НЕ используется.
- `board.jsx` — состояние, drag-drop, заклинания, **атака-стрелка** (`onAttackStart`/`resolveAttack`/
  `paintArrow`/`legalTargets`), awaken, **пикер маны** (`ColorPicker`/`bankAs`), тосты, переключение
  хода, scaling, тултип-делегирование, привязка Tweaks, все начальные данные + стресс-наборы.
- `tweaks-panel.jsx` — демонстрационная панель (в проде не нужна). Тумблеры состояний:
  направление (glass/neon/prism), glow/blur/motif, прожектор, полная рука (10), полный
  стол (8), большой банк маны (ваш / соперник, 20+), много аур (6).

## Demo / preview states (через панель Tweaks или `window.__tw(key, value)`)
`floodlight`, `handFull`, `boardFull`, `bankHuge`, `foeBankHuge`, `aurasMany` — для проверки
предельных случаев: рука близко к 10, стол к 8, раскрытый прожектором враг, большой банк,
много аур. Все случаи держат раскладку без переполнений.
