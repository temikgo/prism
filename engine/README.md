# Prism — движок правил (C++)

Чистая логика игры без сети и графики. Зависимости — только stdlib +
вендоренные single-header `nlohmann/json` и `doctest` (в `third_party/`).
Код намеренно прокомментирован (репозиторий должен быть LLM-friendly): правила
и инварианты поясняются прямо у кода, общая картина — здесь.

## Что уже есть (Phase 1–2)

- **Типы** (`include/prism/types.hpp`): цвета 🔴🟡🟢🔵🟣 + бесцветный, стоимость
  (generic + цветные пипы), `ManaPool` (кристаллы / доступная мана, оплата
  цветных пипов + generic жадно с бесцветного, временная мана для рампа).
- **Карты** (`include/prism/card.hpp`, `src/card.cpp`): `CardDef` + `CardLibrary`,
  загрузка из JSON; хелперы запроса ключевиков (`hasKeyword`, `keywordN`).
- **Игра** (`include/prism/game.hpp`, `src/game.cpp`): два игрока, фазы хода,
  мана-из-карт, призыв, бой ATK/HP (взаимный), добор, fatigue, условие победы.
  Детерминизм от сида (одинаковые действия → одинаковый результат — на этом стоят тесты).

### Ключевики и эффекты — исполняются

Сгруппированы по цвету (каталог и флавор — в `../EFFECTS.md`):

- 🔴 `pierce` (избыток урона в лицо), `bypass` (атака в лицо сквозь провокаторов),
  `self_lifesteal` (лечит себя на нанесённый урон), `lingering` (нанесённые раны
  не лечатся), `regen N` (лечит себя на старте хода).
- 🟡 `provoke` (Taunt), `shield` (поглощает следующий урон), `blind N` (не атакует
  N ходов), `flash N` (ослепляет всех врагов).
- 🟢 `photosynthesis N` (на старте хода +N **временной** маны), `growth N` (+N/+N на
  старте хода), `compost N` (+N/+N когда союзник гибнет), `spores N` (при смерти N
  ростков 1/1).
- 🔵 `freeze N` (не атакует N ходов), `brittle` (двойной урон, пока заморожен).
- 🟣 `split N` (при выходе N постоянных иллюзий — копии ATK, 1 HP, без ключевиков),
  `awaken` (играть из мана-ряда; банкнутый кристалл = 1 generic в стоимость, остаток
  доплачиваешь, слот теряется), `stealth` (нельзя выбрать целью, пока не атакует),
  `mirage` (создать иллюзию любого существа), `haunt` (при смерти оставить иллюзию).
- ⚪ инлайн-действия заклинаний (нейтральные/универсальные): `damage`, `damage_all`
  (выметание), `destroy`, `draw`, `scatter` (вернуть в руку), `freeze`/`blind` и т.д.

**Категории по грамматике §8:** статические (pierce, bypass, provoke, stealth) —
проверяются в правилах; триггерные `OnTurnStart` (regen, growth, photosynthesis);
статусы (freeze, blind, shield, brittle, lingering); реактивные через **очередь
событий** (`Died` → spores/compost/haunt). `on_play`-эффекты идут через диспетчер
`executeAction`. Токены/иллюзии — обычные существа с флагом `token`; синтезированные
дефы токенов хранит сам `Game`. «+N/+N» = +N ATK и +N HP (DEF в игре нет).

Зафиксированные правила MVP (из `../DESIGN.md`), вшитые константами в `game.hpp`:

| Правило | Значение |
|---|---|
| HP героя / броня | 30 / 0 |
| Стартовая рука | первый 4, второй 5 (вся компенсация второго; Coin нет) |
| Лимит руки | 10 (перебор сгорает невидимым) |
| Лимит борда | 8 |
| Мана | из карт 1/ход, рефил до числа кристаллов, свежий доступен сразу |
| Бой | ATK/HP, взаимный (оба бьют своим ATK), одновременно, раны копятся |
| Болезнь призыва | есть (`Creature::sick`) |
| Fatigue | 1, 2, 3… |

## API действий (`Game`)

Каждый метод возвращает `false` и ничего не меняет, если ход нелегален —
можно безопасно «прощупывать».

- `placeCardToMana(handIndex, color)` — жертва карты в мана-ряд кристаллом.
- `playCard(handIndex)` — оплатить и разыграть (существо → борд).
- `attackCreature(attacker, target)` / `attackHero(attacker)` — атака.
- `endTurn()` — передать ход.

## Чего ещё нет (дальше по роадмапу)

- **Ключевики, требующие новых подсистем** (отложены, нужны решения):
  - континуальные баффы (`undergrowth`, `resonance`, `chill`) — нужен слой
    «база + пересчёт» (раздельные базовые/эффективные статы); решить: continuous
    или snapshot-при-выходе;
  - активки (`germinate`) — API активируемых способностей;
  - реактивные из мана-ряда на чужом ходу (`ambush`, `decoy`) — нужен возраст карт
    в мана-ряду + триггер вне своего хода;
  - перехват нацеливания (`refract`, `ward`), отложенный эффект (`delay`),
    `scry` (нужен выбор игрока), `floodlight`/`dispel` (нужны id аур / редакция).
- **Мана-ряд скрыт от противника** — сейчас личности карт в `manaRow` видны всем;
  редактированный вид под игрока (для сервера) скроет их.
- **«Потрогать руками» = настоящий стек** (без выкидной текстовой версии):
  C++-сервер (WebSocket, редактированный вид состояния под игрока) + Godot-клиент,
  минимальным вертикальным срезом, который дальше наращивается.
- Мулиган (сейчас стартовые руки просто раздаются без замены).

## Сборка и тесты

```
cd engine
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build -j
./build/prism_tests        # или: ctest --test-dir build
```

Тест загрузки `sample.json` включается define-ом `PRISM_SAMPLE` (путь к
`../cards/sample.json`), который CMake проставляет автоматически.

## Схема карты (JSON)

```json
{
  "id": "red_undying_borer",
  "name": { "ru": "Неугасимый бур" },
  "text": { "ru": "Пробитие. Регенерация 1." },
  "art": "...",
  "type": "creature",
  "color": ["red"],
  "cost": { "generic": 1, "red": 1 },
  "stats": { "atk": 3, "hp": 3 },
  "keywords": [{ "id": "pierce" }, { "id": "regen", "n": 1 }],
  "effects": [{ "trigger": "on_play", "selector": "chosen_enemy_minion", "action": "freeze", "value": 2 }]
}
```

`id` цвета — языконезависимый токен (`red`/`yellow`/`green`/`blue`/`violet`;
бесцветная стоимость — только `generic`). Видимые строки — в `name`/`text`
(пока только `ru`).
